# falarei-platform

A porta de entrada de `falarei.online`: página inicial, catálogo por categoria, páginas de apresentação dos projetos e o encaminhamento para os deployments de cada projeto.

```bash
npm install
npm run dev        # http://localhost:3000
npm run validar    # verifica projetos/registo.json
npm test
npm run build
```

- **Registar um projeto:** uma entrada em [`projetos/registo.json`](projetos/registo.json).
- **Como publicar, ligar à Vercel, domínio, variáveis:** [`DEPLOYMENT.md`](DEPLOYMENT.md).
